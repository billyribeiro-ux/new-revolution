## Verified findings and changes

1. `src/app.css` is the only runtime Fontsource import owner. Its four installed imports supply normal/italic Montserrat Variable and Sofia Sans Variable. Vite bundles the files locally. `src/hooks.server.ts` selects two upright Latin font preloads, while the article also uses the Latin italic Sofia face. System/metric fallback faces use local installed fonts; the editor offers five approved variable/system choices. Email/platform fallbacks and the press wordmark's native serif stack do not fetch external fonts. Font licensing remains in `static/fonts/LICENSES.txt`.
2. The six watchlist D3 text builders hard-coded `JetBrains Mono, monospace`, although that custom face is not installed or loaded. Replace those unregistered names with `var(--font-mono)`, retaining the shared native monospace stack and avoiding an invented new font dependency. A browser regression verifies the SVG labels use the token.
3. `ARCHCITECURE_AND_SEO.md` retained a commented external Google Fonts recipe and unsupported `wdth` guidance. `docs/CSS_STANDARDS.md` said preloads were omitted even though current hooks preload two faces; the launch tracker also retained a superseded rejection of metric fallbacks. Correct those active instructions against source and live output. This audit changes neither font imports nor preload priority and makes no new FCP/LCP benchmark claim.
4. A latent canonical input gap was reproduced with two failing regression tests: a new/updated post could save a section fragment in `canonicalUrl`, and the metadata builder emitted it. The shared schema now rejects raw fragments in canonical overrides; the renderer strips fragments from legacy/imported overrides before constructing canonical and Open Graph page metadata. Existing article content anchors and graph entity IDs remain intact. See [pre-fix failures](canonical-regression-before.log).
5. Add a source guard to `pnpm check:css` for external font providers/files/stylesheets, misplaced imports/faces and D3 font-token bypasses, plus browser tests for actual loaded FontFace families and request origins across eight representative surfaces. Add a CMS sanitizer regression for injected font stylesheet/style tags. Static scans do not replace network evidence.
6. Make the existing E2E port configurable through `PLAYWRIGHT_PORT` and resolve maintenance URLs from the configured preview origin. This allows the complete suite to run without disturbing the unrelated process on 4173. Correct two authenticated image-flow assertions still expecting the retired non-www graph namespace; keep the assertions and indexing thresholds. The full suite passed with a unique disposable local admin; no Production account or data was used.
7. Add the shared [font/fragment policy](../../FONT_AND_FRAGMENT_POLICY.md) to all 40 existing agent entry points and include the policy itself in the 41-file handoff coverage list. Correct the actual stale guidance and publishing instructions instead of copying unverified advice into every file. Preserve byte-identical SEO-standard copies and historical reference sources.

## Primary references checked

- [Fontsource installation](https://fontsource.org/docs/getting-started/install): installed packages bundle/self-host fonts and use unicode-range subsets.
- [Fontsource preloading](https://fontsource.org/docs/getting-started/preload): preload links use href; preload only critical fonts/subsets.
- [MDN link element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/link): resource links and preload attributes.
- [MDN DOM selection](https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model/Selection_and_traversal_on_the_DOM_tree): CSS selectors require escaping; getElementById does not.
- [Official SvelteKit link options](https://svelte.dev/docs/kit/link-options): native links and fragment scrolling; official MCP also reviewed attachment cleanup and analyzed the full article and watchlist components with no findings.
- [Google canonical guidance](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls) and [URL structure](https://developers.google.com/search/docs/crawling-indexing/url-structure): consistent page canonicals, no fragment canonicals and descriptive URLs, not the supplied arbitrary slug cap.
