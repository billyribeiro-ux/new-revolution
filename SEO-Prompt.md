Review every project file for correctness, necessity, maintainability, and consistency.

- Idiomatic Svelte 5 and SvelteKit 3 patterns, using modern, stable APIs and syntax appropriate to the installed versions.

### 3. Comprehensive SEO & AI-Search Audit

Audit every applicable page and implement technically sound SEO end to end.

Cover:

- Server-rendered, crawlable content and appropriate indexing controls.
- Unique page titles, meta descriptions, canonical URLs, and social-sharing metadata.
- Correct robots.txt, XML sitemaps, redirects, HTTP statuses, and URL structures.
