## Confirmed defect and repair

Before this change, the TOC rail stretched to the end of `.article-main-column`; the panel's fixed viewport maximum was 673.5px in the live 1440×1000 reproduction. At the last FAQ, opening an 87.172px answer moved panel top from −107.422px to −20.25px while page scrollY and FAQ summary position remained unchanged. This is the browser's normal lower-boundary sticky clamp reacting to a changing parent height. Hover movement of the first number/link was not reproduced; existing hover changed color/background/border color without changing geometry.

`src/lib/attachments/article-toc.ts` now measures the actual header, summary, first link and reading boundary. A single animation frame coalesces scroll, resize, media-query and ResizeObserver updates. It changes only the scrollable navigation's height limit; CSS sticky continues positioning the panel. The summary remains outside the scrolling area. When the remaining reading boundary cannot fit a useful summary plus one link, the panel leaves naturally before related content. No article heights, FAQ clipping, focus movement or URL writes are introduced. Cleanup removes listeners, observers, queued frames and owned inline properties.

The article template shares one title/cover/body/FAQ anchor, retains the 900px reading limit, removes decorative tag hashes and uses uncropped 16:9 cover media. Header measurements drive the same anchor/spy offset. Navigation scroll chaining uses `auto`; active-following does not fight hover or focus. Native collapse state remains browser-owned.

It exercises a long 25-link panel, lower-boundary FAQ growth/shrink, measured header changes, disposal with a queued frame, short viewport reachability, numeric heading IDs and replacement heading sets.
