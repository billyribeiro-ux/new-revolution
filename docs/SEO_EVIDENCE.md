## 2. House conventions (NOT Google requirements)

Keep these, label them as ours, and change them only by deciding to, not by citing Google:

- Page `title` ≤ 33 characters before the ` | Revolution Trading Pros` suffix; rendered title 30-60 characters.
- Meta description 140-158 characters, unique per route.
- Exactly one `<h1>`; strict `h1 → h2 → h3`.
- JSON-LD as one `@graph` per page with shared `@id`s.
