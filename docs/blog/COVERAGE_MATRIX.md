## 4. New findings from this run

- **G15 (P1): unknown category and tag 404s carry `Cache-Control: public, s-maxage=300, stale-while-revalidate=86400`.** Vercel's CDN caches `404` responses (cacheable-status list in its CDN-cache docs), so a category or tag created minutes later can keep returning a cached 404, and anyone can fill the cache with arbitrary slugs. Unknown article slugs correctly send no cache header.
- **G5 confirmed:** `?page=999` returns 200 with no articles.
- **G12 narrowed:** no duplicate or missing title, description, canonical or robots tag on any probed template (un-gated table). Open Graph article tags, `og:image` dimensions and author/time tags still need a field-level check.
